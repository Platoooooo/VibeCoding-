# ADR-003: 微信小程序原生框架选择

## 状态

已接受 (2025-01)

## 背景

企业信息展示系统需要移动端入口。需要在微信小程序、H5 网页、React Native 之间做出选择。

## 决策

**选择微信小程序原生框架**，不使用 H5 或 React Native。

## 理由

1. **目标用户群匹配**: 鑫川针织的客户主要在微信生态内，小程序即开即用、免安装
2. **开发成本低**: 原生框架学习成本低，团队可快速上手；H5 需额外处理微信 JS-SDK 兼容性
3. **微信生态集成**: 原生支持微信支付、地图、客服等能力，无需额外接入
4. **云托管支持**: 微信云托管对小程序后端提供原生支持，简化部署
5. **课程目标**: VibeCoding 课程第一阶段作业，小程序原生框架足够演示完整项目

## 后果

- 仅限微信环境运行，无法在浏览器或其他平台使用
- 小程序包大小限制 2MB，需注意资源优化
- WXS 脚本能力有限，部分复杂逻辑需后端处理
- `var` 声明变量是必需习惯（非 ES6 `let/const`）
