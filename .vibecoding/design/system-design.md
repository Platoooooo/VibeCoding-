## 2. 模块划分

| 模块 | 职责 | 关键类 |
|------|------|--------|
| 配置模块 | Security, JWT, CORS, Cache, RateLimit | config/* |
| 控制器模块 | REST API 端点，请求参数校验 | controller/* |
| 服务模块 | 业务逻辑，缓存管理，事务管理 | service/* |
| 数据访问 | JPA Repository，查询方法定义 | repository/* |
| 模型模块 | JPA 实体，数据库映射 | model/* |
| DTO 模块 | 统一响应格式 ApiResponse<T>, PageResponse<T> | dto/* |
| 工具模块 | JWT 令牌生成/验证 | util/* |
| 异常模块 | 全局异常处理，统一错误响应 | exception/* |

## 3. 数据流

```
微信小程序                Spring Boot                 MySQL
    │                        │                         │
    │  GET /api/product/list │                         │
    │───────────────────────►│                         │
    │                        │  ProductService         │
    │                        │  → checkCache(key)      │
    │                        │  → if miss:             │
    │                        │    ProductRepository    │
    │                        │────────────────────────►│
    │                        │◄────────────────────────│
    │                        │  → cache result         │
    │  ApiResponse<Page>     │                         │
    │◄───────────────────────│                         │
```

## 4. 关键设计决策

- **JWT 无状态认证**: 适合小程序前后端分离场景，无需服务端 Session
- **分层架构**: Controller → Service → Repository，职责清晰，易于测试
- **Caffeine 本地缓存**: 产品列表等高频接口使用本地缓存，减少数据库压力
- **Bucket4j 限流**: 保护 API 不被滥用
- **H2 测试数据库**: 单元测试和集成测试使用内存数据库，无需真实 MySQL
